# KenzoShare

A sharing site for a small group of neighbors in Kensington, Philadelphia. Pilot on one block. Open source (license TBD).

Status: planning. No code yet.

## Docs
- `docs/plan.md`: the plan shared with households
- `docs/decisions.md`: what's decided and what's still open
- `docs/comps.md`: existing tools to learn from
- `docs/versions/`: one spec per version
- `docs/prompts/kickoff.md`: prompt to start v0 in Claude Code
- `CLAUDE.md`: project context Claude Code reads every session

## Contributing
Wes maintains. Preston contributes. Edit docs directly or open a pull request. New questions go in `docs/decisions.md`.

## Privacy rule
No neighbors' names, phone numbers, emails, or addresses in this repo. Git keeps history forever, and the repo may go public.
