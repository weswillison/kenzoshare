# v0 Core

## Goal
People can log in, see who's in the group, and have a personal record that later modules write to.

## Must have
- Magic-link login
- Invite a neighbor (records who invited them)
- Profile: edit info, see own activity, stats, and issues
- Household page
- Member directory with contact info and contribution counts
- Report and resolve an issue

## Not in scope
Lending, grocery, car, meals, childcare features. Notifications. Payments. Analytics.

## Done when
On a phone: log in, invite someone, edit profile, see own record, file and resolve a test issue.
