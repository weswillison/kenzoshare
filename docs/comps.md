# Comps

| Tool | Open source | Notes |
|---|---|---|
| myTurn (myturn.com) | No | Most common tool-library platform. Paid. Worth a demo for ideas. |
| tooltrust.org | No | Free, no users yet. |
| Circulate (Chicago Tool Library, github.com/chicago-tool-library/circulate) | Yes | Built for a staffed central library. Supports multiple libraries. Good reference for borrower flows and data model. |
| PVD Things library_os (github.com/pvdthings) | Yes, GPL-3.0 | Software for a cooperative lending library in Providence. |
| Snipe-IT | Yes | Generic asset check-in/check-out. Not built for neighbors. |

## Why build anyway
The comps assume a central library with staff and a storefront. KenzoShare items stay at members' homes, pass member to member, and the site also covers grocery runs, meals, and childcare.
